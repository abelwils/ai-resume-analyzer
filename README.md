#  AI Resume Analyzer

An AI-powered Resume Analyzer web application built using Python and Flask that analyzes resumes against job descriptions and provides smart feedback for ATS optimization and resume improvement.

---

#  Live Demo

👉 https://ai-resume-analyzer-3mxv.onrender.com/

---

#  Features

✅ Resume upload system  
✅ Resume text analysis  
✅ ATS-style keyword matching  
✅ Job description comparison  
✅ Smart resume feedback generation  
✅ Flask backend integration  
✅ Responsive frontend UI  
✅ Online deployment using Render  

---

#  Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Jinja2 Templates
- Render Deployment
